# 🏵️ Rani Lakshmibai Tribute Page

A simple and elegant tribute web page dedicated to the "Warrior Queen of Jhansi" — Rani Lakshmibai.  
This project highlights her bravery, leadership, and contribution to India's freedom struggle.

## 🚀 Features

- Beautiful tribute design with gold-themed layout
- Responsive layout (mobile-friendly)
- Hover effects on the image
- Stylish typography and shadows for better readability
- Footer with credit
- Clean and simple structure (HTML + CSS)

## 🛠️ Technologies Used

- HTML5
- CSS3
